# App Store Connect 입력 가이드 (FlyMate 1.0)

## 1. 앱이 수집하는 개인정보 (App Privacy)

**시작 질문**: "이 앱에서 데이터를 수집합니까?" → **예**

아래 6개 항목을 추가. 각 항목의 공통 답변:
- 목적: **앱 기능**
- 사용자의 신원에 연결됨: **예** (충돌 데이터만 **아니요**)
- 추적 목적으로 사용: **아니요** (전부)

| 카테고리 | 데이터 유형 | 신원 연결 |
|---|---|---|
| 연락처 정보 | 이메일 주소 | 예 |
| 연락처 정보 | 이름 | 예 |
| 식별자 | 사용자 ID | 예 |
| 식별자 | 기기 ID (푸시 토큰) | 예 |
| 사용자 콘텐츠 | 사진 또는 비디오 | 예 |
| 사용자 콘텐츠 | 기타 사용자 콘텐츠 (피드백·댓글) | 예 |
| 진단 | 충돌 데이터 | **아니요** |

> Privacy Manifest(`Resources/PrivacyInfo.xcprivacy`)에 이름·사용자 ID·구입 내역을 추가해둠.
> 기기 ID·충돌 데이터는 Firebase SDK 자체 매니페스트가 선언하므로 앱 매니페스트에는 불필요.

### 설명
```
FlyMate는 승무원, 아나운서 등 영상면접을 준비하는 사람들을 위한 스터디 피드백 앱입니다.

혼자서는 알기 어려운 표정, 말투, 자세 — 함께 준비하는 스터디 멤버의 눈으로 확인하세요.

■ 스터디 그룹
• 최대 8명의 멤버와 스터디를 만들고 초대 코드로 간편하게 참여
• 같은 목표를 가진 사람들과 꾸준히 연습

■ 영상 피드백
• 연습 영상을 업로드하고(최대 3분) 멤버들에게 피드백 요청
• 영상을 보며 피드백과 댓글로 의견 교환
• 받은 피드백을 모아보고 개선 포인트 정리

■ 스터디 모집
• 모집 게시판에서 나에게 맞는 스터디를 찾거나 직접 모집

■ 알림
• 새 피드백, 댓글이 달리면 푸시 알림으로 바로 확인

이용약관 및 개인정보처리방침은 앱 설명 하단 링크에서 확인할 수 있습니다.
```

## 4. 인앱 구독 — 1.0에서는 제외

1.0에는 구독 진입점이 없음(코드는 있으나 UI 비노출). ASC에 구독 상품을 등록하지 않고,
App Privacy에도 "구입 항목"을 선언하지 않는다.

추후 구독 활성화 버전 제출 시:
- 구독 그룹 생성 + `com.flymate.premium.monthly` / `.yearly` 등록 (첫 IAP는 버전과 함께 심사 제출)
- App Privacy에 "구입 항목 > 구입 내역" 추가
- `PrivacyInfo.xcprivacy`에 `NSPrivacyCollectedDataTypePurchaseHistory` 추가
- 앱 설명의 "FlyMate 프리미엄" 문단 복원
